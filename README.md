CNC Drawer Organizer v2.3

- Scheda tecnica unificata per tutti i cassetti, originali e personalizzati.
- Selezione tipologia utensile in ogni cassetto: inserti tornitura, inserti trapezoidali, inserti metrici/GAS, punte/frese, maschi, bareni, altro.
- Maschi metrici con misure e passi standard selezionabili (es. M6: 1 / 0,75 / 0,5 mm).
- Inserto tornitura con forma ISO, dimensione, marca, grado, lavorazione e materiali ISO.
- Cassetti personalizzabili, ordinabili ed eliminabili se vuoti.
- Conservate le chiavi di archiviazione e backup delle versioni precedenti.
- Eventuali utensili del vecchio modulo generico vengono migrati come 'Altro utensile' conservando i dettagli nel campo descrizione.

INSTALLAZIONE: sostituire index.html su GitHub Pages. Esportare prima il backup JSON.
NOTA: sintassi JS verificata; effettuare prova funzionale su telefono.
